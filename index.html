Política de Privacidade

YAMISTUDIO — Hub PausaPraAnime

Última atualização: agosto de 2026

Esta página descreve como a ferramenta pessoal de publicação e curadoria de conteúdo mantida por YAMISTUDIO / Yan Stutz, usada para operar a página @pausapraanime no Instagram, trata dados ao se conectar a APIs de terceiros como a do Pinterest.

O que essa ferramenta é

Um aplicativo de uso pessoal e único. Não é distribuído, vendido ou disponibilizado para outras pessoas ou empresas. Só o próprio Yan Stutz, em nome da YAMISTUDIO, opera e acessa esta ferramenta.

Que dados são acessados

Ao usar a API do Pinterest, a ferramenta faz buscas de pins públicos por palavra-chave, para localizar imagens de referência a usar em conteúdo editorial próprio (capas e carrosséis de anime). Nenhum dado de conta de terceiros (seguidores, mensagens, informações privadas de outros usuários) é acessado, coletado ou armazenado.

O que NÃO é feito com os dados

  • Não há coleta de dados pessoais de visitantes ou de outros usuários do Pinterest.
  • Não há revenda, redistribuição ou uso publicitário/targeting com o conteúdo acessado.
  • Não há compartilhamento de dados com terceiros.

Armazenamento

Imagens encontradas via busca ficam salvas localmente, apenas na máquina do operador, até serem usadas (ou descartadas) na produção de conteúdo para @pausapraanime.
